# Disclaimer & Credits

## AI tools used

This project was built with assistance from AI coding tools during the hackathon. Documenting this
for transparency:

- **Claude Code (Anthropic)** — used as an AI pair-programming assistant for parts of the backend
  implementation (FastAPI routes, database schema, service layer) and for generating this `/docs`
  folder from the existing codebase.
- **Claude API, OpenAI API, Ollama API** — used to generate the AI-written activity report in `GET /report/{user_id}`.
- **Google Stitch** - UI UX and Frontend mockup design assistance.
- HuggingFace Transformers:
**facebook/mask2former-swin-tiny-coco-instance**: for segmentation of waste photos
**watersplash/waste-classification**: for classifying different types of waste, which is Battery, Biological, Brown-grass, Cardboard, Clothes, Green-Glass, Metal, Paper, Plastic, Shoes, Trash, White-Glass
- **gemini 3.1 pro, gemini 3 flash, chatgpt, deepseek, claude** for brainstorming

All AI-assisted code and content was reviewed by the team before being committed.
